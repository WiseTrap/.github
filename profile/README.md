## About WiseTrap

WiseTrap is a security-focused project developed to simulate real login environments and capture suspicious credential attempts for analysis and awareness purposes.

It is designed as a **web-based credential honeypot** that mimics a normal login panel, logs user activity such as IP address, timestamp, and login attempts, and presents fake data after authentication.

This project was created as part of a graduation project at [WISE University](https://www.wise.edu.jo/?WiseTrap).

## Features

- Fake login panel that looks like a real system
- Logs IP address, timestamp, and user attempts
- Displays simulated data after login
- Built using native PHP OOP
- MVC architecture for clean and scalable code
- MySQL database integration
- Simple and maintainable structure
- Suitable for cybersecurity education and demonstrations

---

## Technical Philosophy

WiseTrap was developed with a focus on understanding and building the core architecture manually.

### Backend

- No external backend libraries or frameworks were used
- No Composer dependencies
- No third-party packages
- Entire backend built from scratch using native PHP OOP and MVC architecture

### Frontend

- Frontend styling uses Bootstrap only
- No frontend frameworks were used
- No JavaScript build tools or package managers

This approach helps demonstrate the internal structure and workflow of a custom-built PHP MVC application without relying on external ecosystems.

---

## Why WiseTrap?

WiseTrap helps demonstrate how attackers may target exposed login pages, weak credentials, or forgotten panels.

It is useful for:

- cybersecurity awareness
- educational demonstrations
- honeypot research
- observing suspicious login behavior
- showing the importance of secure authentication
